# Sai Ganesh — Developer Portfolio

AI/ML & Software Developer portfolio built with React 18, Vite, Tailwind CSS, Framer Motion, Lucide React, and interactive HTML5 Canvas.

## Features
- **Theme**: AI / Intelligent Systems Aesthetic (Deep Navy, Violet & Purple accents, Canvas particle/neural network backdrop)
- **Sections**: Hero, About, Skills, Projects, What I Build, Education, Achievements, Contact
- **Theme Toggle**: Dark / Light mode toggle with persistent state
- **Responsive**: Fully responsive layouts with customized UI components

## Development
```bash
npm install
npm run dev
```
